# C64 games

Reverse-engineered C64 games. Each game has its own folder with the original disk, the knowledge, the rebuilt source, the test scenarios and the documentation.

| Game | |
|---|---|
| [Bruce Lee](bruce_lee/README.md) | Datasoft 1984, by Ron J. Fortier. How the program works, from the cold start to the last room: rooms, actors, combat, graphics, sound and music. A byte-identical source and a loader without the crack. Three cracked releases (SAEGER, TBC, DC) compared byte by byte, each a build of the same source. |
