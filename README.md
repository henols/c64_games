# C64 games

Reverse-engineered C64 games. Each game has its own folder with its reference files, the knowledge, the rebuilt source, the test scenarios and the documentation. A reference file can be a commercial release, a crack or a snapshot.

| Game | |
|---|---|
| [Barbarian](barbarian/README.md) | Palace Software 1987, Barbarian: The Ultimate Warrior. Four projects in one group folder: part 1 (Combat Practice) and part 2 (the story game), each in two builds. The fighters, the hit check, the computer opponent and the final stage with Drax and the princess. The pictures, the sprites and the music. A hit-check bug that reads the wrong memory, and a dead two-player mode in part 2. Commodore 128 code and a cartridge header in the program. Three cracks (Raw Deal Inc., Hotline with its trainer, Fairlight) build from byte-identical sources. |
| [Blue Max](blue_max/README.md) | Synapse Software 1983, by Bob Polin, C64 version by Peter Adams. A biplane flies over a diagonally scrolling landscape. The pages cover the map rows and sections, the airfields with landing and service, and the enemy planes, flak and special targets. They also cover the target city, the rank screen and the tune player. The copy protection is in the values of the original loader, and the first-stage loader survives in the Bandit dump. Development leftovers: an old charset, debug routines with a monitor exit and a disabled invincibility toggle. Three cracks (anonymous, The Bandit, Derbyshire Ram with two trainers and a Synsoft title line) build from one byte-identical source. |
| [Boulder Dash](boulder_dash/README.md) | First Star Software 1984, by Peter Liepa with Chris Gray. Two builds, each with its own byte-identical source. v1 is the Micro Fun build (the Charsoft crack). v2 is the Statesoft build (an original tape, the Donald Duck & Co and Roan cracks). The cave scan and the elements, the cave data format, the double-buffered scrolling screen, the title, the demo and the tune. A disk check that no release calls, the symbol-table fragments of the developer and a scan stop at the magic wall. The Statesoft loading picture of the tape at the start. |
| [Bruce Lee](bruce_lee/README.md) | Datasoft 1984, by Ron J. Fortier. How the program works, from the cold start to the last room: rooms, actors, combat, graphics, sound and music. A source that is byte-identical to the SAEGER crack, and a loader without the crack. Three cracked releases (SAEGER, TBC, DC) compared byte by byte, each a build of the same source. Nobody examined a Datasoft release. The Datasoft title picture, restored from the TBC crack, at the start. A fault of the game stops it at some room changes. |
| [Falcon Patrol](falcon_patrol/README.md) | Virgin Games 1983, by Steve Lee. A two-way scrolling shoot'em-up with a jet that hovers and lands. The flight model, the enemy waves and the kill test, the landscape map, the radar and the title with its high-score table. Code at fixed addresses with old copies and dead routines, and a start-up hang in one start of six. Three cracks (T.Bombardieri, Derbyshire Ram with its trainer, RGR) build from one byte-identical source. |
| [Hover Bovver](hover_bovver/README.md) | Llamasoft 1983, by Jeff Minter. Gordon mows the lawns of his neighbours with a borrowed mower while the neighbour chases him and Rover the dog helps. The main loop, the actors and their modes, the 16 lawn layouts, the screens, the tune player with its NTSC note table. The memory of Minter's assembler and a source line of lawn 14 in the block, and a speed bug that keeps lawn 16 as slow as lawn 1. Three cracks (The Friendly Programmer, Kraksnax "US/Canadian edition", Hokuto Force with six trainers and a high-score saver) build from one byte-identical source. |
| [Koala Painter](koala_painter/README.md) | Koala Technologies 1983, by Audio Light: the paint program of the KoalaPad, not a game. Two builds of the same source, each with its own byte-identical source: v1 (the Mayday! release, from an original disk) and v2 (the TBC and MAM cracks of 1984). The KoalaPad input, the menu, the 16 tools, the script language that draws the menu, the Storage disk menu and the Koala picture file. The disk protection of each build, the symbol-table fragments of the developer and CP/M bytes in the title file. The Koala Technologies title picture at the start. |
| [The Way of the Exploding Fist](exploding_fist/README.md) | Melbourne House 1985, by Beam Software. Two versions of the game, each with its own byte-identical source: version I (releases 2010 and Shadow) and version II (SCC and Mr. Z). The development from version I to version II: a dead bull bonus round and sample player in version I that version II makes live, keyboard control, a high score table and corrections. The Melbourne House title picture and the speech sample of the original loading stage at the start. |
